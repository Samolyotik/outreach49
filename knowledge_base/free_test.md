# Free Test

Демо-бот и бесплатный тест — два разных формата.

Демо-бот доступен на сайте без ограничения по времени. Он знакомит с продуктом,
примерами запросов и публичными тарифами, но не является индивидуально
настроенной тест-системой.

Бесплатный тест — это отдельный доступ к системе сроком до трёх дней, чтобы
человек мог проверить механику поиска сигналов спроса на своей задаче без
платного запуска. Для направления
`Авто из-за границы` после явного согласия действует автоматическая выдача одноразовой ссылки
на бота для бесплатного теста; для всех остальных сфер доступ подключается через менеджера.

Автоматическая ветка использует утверждённый lifecycle бота для бесплатного теста. В ветке через
менеджера формат доступа, условия подключения и точный сценарий подтверждает
менеджер. Автоматизация может назвать общий верхний предел теста «до трёх
дней», но не должна обещать конкретный объём сигналов.

Автоматизация может объяснить общую ценность теста и снять базовые вопросы. После согласия она либо
выдаёт одноразовую ссылку на бота для бесплатного теста в активной
автоматической сфере, либо передаёт диалог менеджеру.
Запросы на созвон, менеджера, индивидуальные условия или пилот всегда передаются менеджеру.

Во время бесплатного теста или использования демо-бота человеку может быть
доступно промо `настройка/внедрение — 0 ₽`. В других случаях его можно
согласовать через менеджера. В утверждённом lifecycle бота для бесплатного теста кнопка до
точного `test_expires_at` только резервирует обращение по промо и создаёт
коммерческий handoff; она не является оплатой и не запускает пилот
автоматически. Окончательную применимость промо, тариф, scope и дату запуска
подтверждает менеджер.

## Что можно говорить автоматически

- Тест нужен, чтобы безопасно посмотреть систему и понять, есть ли живые сигналы спроса в нише до обсуждения платного формата.
- Демо-ботом на сайте можно пользоваться без ограничения по времени; бесплатный тест системы длится до трёх дней.
- Бесплатный тест — не просто подборка примеров сообщений, а отдельный доступ к системе: автоматически
  через бота для бесплатного теста для `Авто из-за границы`, через менеджера для остальных сфер.
- Для первого согласия достаточно понять общий интерес: человеку полезнее искать потенциальные заявки или проверить спрос в нише.
- Сам факт интереса к демо не требует handoff, если человек пока спрашивает только общую механику.
- Согласие на бесплатный доступ или запуск теста в `Авто из-за границы` направляется в
  автоматическую ветку; явный запрос менеджера/созвона всегда создаёт handoff. Для остальных сфер
  согласие на доступ создаёт handoff.
- Если человек спрашивает `что потом?` / `что дальше?`, для автоматической ветки нужно объяснить
  выдачу одноразовой ссылки на бота для бесплатного теста и самостоятельный
  запуск; для остальных сфер — связь менеджера
  и согласование доступа.
- Основной CTA соответствует активной ветке: предложить автоматический доступ
  через бота для бесплатного теста для
  `Авто из-за границы` либо передать менеджеру заявку для остальных сфер. Предложение прислать
  несколько примеров не должно заменять этот CTA.
- После handoff человек может продолжать задавать low-risk вопросы в текущем диалоге, пока менеджер занимается доступом.

## Что нельзя обещать автоматически

- срок теста больше трёх дней без индивидуального подтверждения менеджером;
- ограничение по времени для демо-бота;
- выдачу доступа вне точного активного allowlist автоматической ветки;
- автоматический запуск платного пилота;
- бронирование демо без менеджера;
- фиксированное количество сигналов;
- продажи, ROI или снижение стоимости лида;
- индивидуальные коммерческие условия.
