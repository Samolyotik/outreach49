# Reply Few Shots

Назначение: короткие эталонные ответы для LLM. Использовать как style / format context, а не как источник новых фактов.

CTA выбирается по `conversation_context.free_test_access_branch`: `automatic` означает
одноразовую ссылку на бота для бесплатного теста для `Авто из-за границы`; при отсутствии этого контекста используется
ветка через менеджера.

Ответ: "Сайты мы не запускаем. ТГ РАДАР занимается поиском и анализом сообщений, сигналов спроса и потенциальных лидов. На некоторых тарифах отдельные этапы общения можно автоматизировать; конкретный сценарий уточняет менеджер."

## Skepticism - no pressure

Вопрос: "Это очередной парсер?"

Ответ: "Понимаю скепсис. Тут смысл не в выгрузке всех сообщений подряд, а в отборе сигналов спроса из подключённых под проект источников: где человек реально ищет решение, подрядчика или рекомендацию. Дальше шум отсекается, а команда получает только рабочие сообщения с контекстом."
