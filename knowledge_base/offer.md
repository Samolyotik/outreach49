# Offer

Базовый оффер для первого касания: короткий бесплатный тест / демо с несколькими примерами релевантных сигналов по нише.

Цель теста: дать человеку безопасно оценить качество сигналов до обсуждения платного формата.

## Основной продаваемый оффер

ТГ РАДАР запускает управляемый канал входящих запросов из мессенджеров и соцсетей под нишу клиента: подбор открытых и доступных закрытых источников, поиск сигналов, ИИ-фильтрация, рабочий чат / Telegram-CRM, предложенные ответы, аналитика и сопровождение. Для большинства проектов используются Telegram, ВКонтакте и Max, а конечный набор площадок определяется под проект.

## Для кого

Для компаний, где потенциальные клиенты уже обсуждают задачи в мессенджерах и соцсетях, спрашивают рекомендации, сравнивают варианты, ищут подрядчиков / товары / услуги или жалуются на текущего поставщика.

## Обещание оффера

Клиент получает не рекламные клики, а найденные сообщения с проявленным спросом: текст запроса, доступную для передачи ссылку на источник, контекст, приоритет и вариант первого ответа. В зависимости от тарифа обработка может быть ручной либо включать автоматизацию отдельных этапов.

## Как продавать в автоматическом диалоге

Не собирать длинный технический бриф до CTA. Сначала коротко объяснить механику, ответить на
low-risk вопрос и предложить бесплатный показ / доступ по active sector branch. Для
`Авто из-за границы` явное согласие ведёт к одноразовой ссылке на бота для
бесплатного теста; для остальных сфер — к
handoff менеджеру. Запрос конкретных условий, договора, оплаты, менеджера или созвона всегда ведёт
к handoff.
